Politique de confidentialité

Qui est responsable de vos données ?

Kerim AKGUN EI (KNV.CORP). Pour toute question : knv.corp.78@gmail.com.

Quelles données sont collectées ?

Celles que vous envoyez avec le formulaire de devis : nom, activité, ville, email et/ou téléphone, et votre message. Si vous m'écrivez par email ou sur WhatsApp, je reçois aussi les informations de votre message. Comme pour tout site, l'hébergeur GitHub enregistre l'adresse IP des visiteurs pour des raisons de sécurité.

Pourquoi ?

Pour répondre à votre demande et vous envoyer un devis. Vos données ne servent à rien d'autre : pas de publicité, pas de revente.

Base légale : votre demande de devis (mesures précontractuelles, article 6.1.b du RGPD) ; pour les factures, l'obligation légale comptable (article 6.1.c).

Qui les reçoit ?

Personne d'autre que moi ne les lit. Formspree (formulaire) et GitHub (hébergement du site) les traitent pour mon compte ; ce sont des sociétés américaines. GitHub adhère au Data Privacy Framework UE–États-Unis (décision d'adéquation de la Commission européenne du 10 juillet 2023). Si vous m'écrivez par email (Gmail, Google) ou sur WhatsApp (WhatsApp Ireland, groupe Meta), ces services traitent aussi vos données selon leurs propres règles.

Si vous ne devenez pas client : 3 ans après votre dernier message. Si vous devenez client : pendant notre collaboration, puis 3 ans. Les devis et factures sont conservés 10 ans, comme la loi l'exige.
